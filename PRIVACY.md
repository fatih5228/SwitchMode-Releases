# SwitchMode Privacy Policy

**Last updated:** 2026-08-10  
**Developer:** Fatih AYDIN  
**Contact:** https://github.com/fatih5228

## Summary

SwitchMode is a local Windows utility that switches light/dark theme from the system tray. It does **not** collect, store, transmit, or sell personal data.

## Data collection

SwitchMode does **not**:

- collect personal information
- require an account or login
- use analytics or advertising SDKs
- access your files, contacts, camera, microphone, or location
- send data over the internet during normal use

## Local settings

The app may store simple preferences on your device only, such as:

- start with Windows on/off
- which theme targets to toggle
- notification preference

These settings stay on your PC (for example under your user AppData folder or Windows startup settings).

## Windows theme changes

When you toggle theme, SwitchMode updates your current Windows user personalization settings so light/dark mode can change. This is a local system setting change, not data collection.
